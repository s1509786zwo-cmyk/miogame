# いろ(iro)— 開発リポジトリ

精神科病棟を舞台にした、ブラウザで動く 2D アドベンチャー風 RPG。
HTML + JavaScript のみ(外部ライブラリなし)。Canvas 2D / 内部解像度 320x240 / 整数倍拡大。

## 使い方

- `python3 -m http.server` などで配信し、`index.html` を開く(`file://` でも動くが、PNG 配置後は http 推奨)。
- 操作: 矢印/WASD 移動、Z(Enter) 決定、X キャンセル、C ナースコール。画面下のボタンでも操作可。
- デバッグ(URL に `?debug`): `T` 現実⇄向こう側のパレット切替、`G` 空の熟れ度+10、`S` 保存、`B` 第1戦を戦闘する。

## ファイル構成

```
index.html   … 画面レイアウト・拡大表示・画面上ボタン
game.js      … エンジン(入力/アセット/会話/HUD/タイトル/探索/セーブ/音)
maps.js      … 病棟のマップデータ(1画面=1マップ。廊下のみ40x15でカメラ追従)
story.js     … シナリオ全文(決定稿)。ここだけ書き換えれば台詞を差し替えられる
assets/      … PNG 素材(無くても仮矩形で動く。プリロード失敗はゲームを止めない)
  characters/ mio_real mio_other kaede kaede_gauze mother doctor nurse_night staff_meal hana   (48x96 = 横3コマx縦4行、行の順:下・上・左・右、1コマ16x24)
  monsters/   mike(32x32x2) gyorome honey_queen(96x96x2) gatekeeper_l(96x128x2) gatekeeper_s witch_0..witch_4(128x160)
  tiles/      tileset_real tileset_other (16x16タイル)
  bg/         320x240: real_* other_* title battle_bg_123 battle_bg_4_0..4 transition_white ending_grave ending_entrance bad1_room bad7_box
```

※ ファイル名と寸法を守れば `assets/` に置くだけで仮矩形から自動で差し替わる。
※ 素材が規定寸法と違う場合は「1枚絵」として自動でリサイズ表示する(現在同梱の下書きPNGはこれ)。
※ 現実シーン合成時にはグレースケールフィルタを強制適用(素材がカラーでもズレない)。

## ステージ1の確認手順

1. タイトル画面に「いろ」「この作品には、精神疾患と、家族の死を扱う場面があります」が出る。↑↓で「あそびかた」も確認。
2. 「はじめる」→ プロローグ全文が会話ウィンドウで流れる(Zで送る/Xで閉じる)。
3. 病室に出現。左上に「自分の病室」が数秒。右上に「目的:病棟を歩いてみる」。下部に「入院3日目・朝」。
4. ベッド・窓・ナースコールなどを Z で調べる。病室の下のドアから廊下へ(暗転)。
5. 廊下から談話室(ハナさんと会話)/ナースステーション(楓・医師)/食堂(看護助手)/中庭/面会室に入れることを確認。
6. 廊下上部、真ん中より右の×印の扉(屋上)を調べると「鍵がかかっている」。中は描いてあるが入れない。
7. C でナースコールのデモ表示(熟れ度 0 のとき:楓さんの会話)。
8. `?debug` を付けて `S`(保存)→ タイトルに戻ると「つづきから」が増える。`G` でゲージ、`T` で現実⇄向こう側(色・パレット・BGMが切替)。

## ステージ1で確定した設計ルール(後段で壊さない)

- `window.IRO`(=Game): `state`(章/day/time/world/map/x/y/objective/ripeness/ripeCount/flags)・`setScene`・`transition`・`MAPS`・`STORY` を公開。戦闘は `battle` シーンとして追加する。
- マップは文字グリッド(`# . w F D G P`)。出入口は `doors:[{x,y,to,tx,ty}]` の相互リンク。
- シナリオ本文は `story.js` のみ。分岐テキスト・バッドエンド・ヒント・手紙7通・エンディング文はすべて定義済みで、後段は `director` が消費する。
- `state.flags.bad7seen` が立つと、タイトルに「ナースコールを、押す」が出る(ステージ5で解放)。

## ステージ2の確認手順

1. `?debug` 付きで開き、探索中に `B` を押すと「ギョロメ」戦が始まる(プロローグ→戦闘)。
2. メニューは ↑↓ で「たたかう/みのがす」を選び Z。みのがすを2回選ぶと影が闇に溶けて勝利→現実復帰。
3. 「たたかう」だと攻撃バーが出る。白い線が往復するので Z で中央(緑)止めると大ダメージ。端(赤)は空振り。3回ほど当てて倒すと……バッド1「閉ざされた部屋」→ヒント→タイトル。
4. 弾幕フェーズは四角い枠の中を矢印キーで動く。光の円(狙撃)と虹彩の輪に当たると HP が減り、0 にするとミケが「ほらね」と言って戦闘を最初からやり直す。
5. 画面右端にミケの囁きが縦書きで常時流れる。
